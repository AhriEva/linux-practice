# Сравнение с Cargo

Cargo используется только как независимый эталон. Приложение dependencies
не запускает Cargo и самостоятельно читает sparse index, разбирает версии,
активирует features и обходит зависимости.

## Порядок загрузки (этап 4)

Проверено на macOS Apple Silicon 16 октября 2026 года, Cargo 1.99.1.
Для getrandom@0.2.16 приложение при глубине 20 получило:

```text
cfg-if@1.0.5
libc@0.2.190
wasi@0.11.1+wasi-snapshot-preview1
getrandom@0.2.16
```

Независимый запуск `cargo build --jobs 1 -vv` на проекте
examples/cargo/getrandom показал строки Compiling в порядке:

```text
libc v0.2.190
cfg-if v1.0.5
getrandom v0.2.16
comparison-getrandom v0.1.0
```

Оба порядка ставят зависимости перед getrandom. Перестановка независимых
libc/cfg-if допустима: топологическая сортировка не уникальна. Приложение выбирает
готовый узел по алфавиту, Cargo использует собственный планировщик. wasi присутствует
в графе приложения, потому что рассматриваются зависимости для всех target,
а сборка Cargo выполнялась только для текущей macOS. comparison-getrandom —
вспомогательный проект сравнения и не является зависимостью getrandom.

При цикле приложение отказывается выдавать полный порядок. Усечённый глубиной
или фильтром граф даёт порядок только исследованного подграфа.
