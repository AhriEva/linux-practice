# Демонстрация варианта 18

## Быстрый запуск

Из каталога проекта выполните `./scripts/demo.sh`.
Покажите заголовок с реальными username и hostname, приветствие из `/motd`,
отладочные параметры и вывод стартового скрипта. После скрипта окно остаётся
открытым. Далее вводите команды вручную, нажимая Enter.

## Интерактивная часть

```sh
conf-dump
ls -al /
cd "/home/student/folder with spaces"
ls "a b.txt"
cd ..
tree -L 2
whoami
cd /
uniq /lines.txt
uniq -c /lines.txt
uniq -d /lines.txt
uniq -u /lines.txt
mkdir -p "/practice/new folder/child"
chmod -R 700 /practice
ls -l /practice
tree /practice
```

Объясните: `uniq` удаляет соседние повторы. Последняя строка `alpha` остаётся,
потому что перед ней находится `gamma`. `mkdir -p` создаёт несколько уровней,
`chmod -R` меняет права на всех узлах поддерева; в `ls -l` видна маска `700`.

## Ошибки и восстановление

```sh
unknown
cd /missing
cd /lines.txt
ls -z
ls "незакрытые кавычки
mkdir /practice
chmod 999 /lines.txt
chmod 000 /lines.txt
uniq /lines.txt
chmod 644 /lines.txt
uniq /lines.txt
exit extra
exit
```

Каждая некорректная строка даёт понятную ошибку. После неё можно продолжить
работу. Неверный `exit extra` оставляет окно открытым, корректный `exit` закрывает.

## Работа только в памяти

Запустите приложение снова с тем же образом: каталога `/practice` больше нет,
исходные права восстановлены. Файл XML не изменился. Это дополнительно
проверяется автоматическим тестом SHA-256.

## Сценарии и история

`./scripts/check.sh` проверяет все этапы. В scenarios stage2–stage5 намеренно
включены ошибки; видны ввод, вывод, имя скрипта и номер строки ошибки.
Комментарии используют синтаксис C++ `//`. После ошибки выполняется следующая
строка, а после `exit` — нет.

Покажите `git log --oneline --decorate` и пять меток этапов.
В первых двух этапах `ls`/`cd` являются заглушками, в третьем загружается VFS,
в четвёртом появляются основные команды, в пятом — изменение состояния.

Сценарии предназначены для демонстрации реализованных режимов; преподаватель
может вводить собственные команды и менять путь к VFS через параметры запуска.
