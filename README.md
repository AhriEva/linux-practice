# Вариант 18 — эмулятор оболочки

C++17, Qt 6 Widgets. Этап 1: графический REPL, аргументы в кавычках,
команды-заглушки `ls`, `cd`, команда `exit`, диагностика ошибок.
Заголовок содержит настоящие имя пользователя и имя компьютера.

Сборка: `cmake -S . -B build && cmake --build build`.
Запуск: `./run.sh`. Тесты: `ctest --test-dir build --output-on-failure`.

Демонстрация: `ls "a b"`, `cd /tmp`, `unknown`, `exit extra`, `exit`.

## Этап 2

`--vfs path` задаёт путь VFS, `--startup path` — путь стартового скрипта.
`conf-dump` печатает параметры в виде ключ=значение; они также видны при старте.
Комментарии скрипта используют синтаксис C++ `//` вне кавычек в начале слова.
Ошибки помечаются именем скрипта и номером строки; выполнение продолжается.
`exit` завершает скрипт и сеанс. Дополнительный `--headless` запускает сценарий
без окна, возвращая код 1 при ошибках. Пример: `scripts/config-demo.sh`.

## Этап 3

XML загружается в память; исходный файл открывается только для чтения.
`<vfs>` — корень, `<dir name="...">` — каталог, `<file name="...">` — файл.
Текст хранится внутри элемента, бинарные данные — с `encoding="base64"`.
Необязательные права `mode="755"` задаются восьмерично.
Корневой файл `/motd` отображается перед стартовым скриптом.
Примеры: minimal.xml, files.xml, full.xml (три уровня каталогов).
