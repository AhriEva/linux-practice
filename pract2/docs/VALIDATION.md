# Результаты проверки

Проверено 16 октября 2026 года на macOS Apple Silicon, AppleClang 21,
CMake 4.4.4, Qt 6.12.0. Сборка с `-Wall -Wextra -Wpedantic` прошла без
предупреждений компилятора. Требования исходников: C++17, CMake 3.16+, Qt 6.4+.

| Набор | Результат |
| --- | --- |
| config_tests | Параметры, URL, тестовый файл и dump: пройден |
| version_tests | SemVer, prerelease, диапазоны, wildcard и ошибки: пройден |
| repository_tests | HTTP на локальном сервере, кеш, index path, JSON, features: пройден |
| graph_tests | BFS, глубина, фильтр, общие узлы, цикл, повторное объединение features: пройден |
| order_tests | Зависимости раньше родителей, детерминизм, цикл: пройден |
| render_tests | PlantUML, ASCII, общие узлы, циклы и отметки глубины: пройден |
| cli_tests | Реальный процесс, ошибки каждого параметра и комбинированный вывод: пройден |

CTest: **100% tests passed, 0 tests failed out of 7**.
`scripts/check.sh` завершился с кодом 0. Он проверил четыре тестовых репозитория,
ограничение глубины, фильтрацию и ожидаемую ошибку порядка в циклическом графе.
Внешняя сеть для этих проверок не требуется.

Выполнено отдельное сравнение с реальным Cargo 1.99.1. Для itoa@1.0.15,
getrandom@0.2.16, rand_chacha@0.3.1 совпали все узлы, версии и рёбра с
`cargo tree --target all -e normal,build`. Соответственно получены 1/4/9 узлов
и 0/3/12 рёбер. Сопоставление выполнено по текстовому PlantUML и независимому
выводу Cargo с глубинами; подробности находятся в COMPARISON.md.

Для порядка дополнительно выполнена реальная сборка getrandom через
`cargo build --jobs 1 -vv`. Различия объясняются платформой и допустимой
перестановкой независимых узлов, а не нарушением зависимостей.

Примеры PlantUML проверены тестами структуры: узлы, aliases, рёбра, границы
блока и пометки. Внешний рендерер PNG/SVG в эту проверку не входил;
снимки `.puml` содержат текст диаграмм для просмотра выбранным средством PlantUML.
Windows/Linux здесь не запускались. Сборка для них предусмотрена через CMake.
